# 🍽️ Sistema Cantina

Sistema de pedidos para a cantina da faculdade, com cardápio digital, controle de estoque e painel de chamada de pedidos.

> Projeto acadêmico desenvolvido no curso de Análise e Desenvolvimento de Sistemas (ADS).
> Feito por mim e demais colegas de classe

## ✨ Funcionalidades
- Cadastro e controle de produtos
- Controle de estoque
- Cardápio digital com preços e disponibilidade
- Registro de pedidos
- Painel de chamada de pedidos
